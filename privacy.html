1. Общие положения

Настоящая политика описывает общие принципы обработки персональных данных посетителей сайта lscate.ru и лиц, направляющих заявки Love Story Catering.

2. Какие данные могут обрабатываться

При отправке формы пользователь может передать имя, номер телефона, тип и дату мероприятия, количество гостей и иные сведения, которые самостоятельно укажет в сообщении. При согласии на аналитические cookie могут обрабатываться технические сведения о посещении сайта с помощью Яндекс Метрики.

3. Цели обработки

Данные используются для обработки обращения, связи с пользователем, подготовки предложения по мероприятию, улучшения качества сайта и анализа его использования при наличии соответствующего согласия.

4. Основание и срок обработки

Обработка выполняется в объёме, необходимом для ответа на обращение и взаимодействия с пользователем. Пользователь может обратиться с запросом об уточнении или прекращении обработки данных по адресу info@lscate.ru.

5. Передача данных

Данные могут передаваться сервисам, технически необходимым для работы сайта и обработки обращения, в пределах их функций. Отправка заявки через WhatsApp приводит к переходу в соответствующий сервис и регулируется также его условиями.

6. Cookie и аналитика

Необходимые технические данные используются для работы сайта. Яндекс Метрика загружается только после выбора пользователем аналитических cookie. Подробнее — в политике использования cookie.
