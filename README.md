# Love Story Catering — GitHub Pages

Готовая статическая версия сайта Love Story Catering для публикации на GitHub Pages.

## Структура

- `index.html` — разметка сайта, SEO, Яндекс Метрика 111456931.
- `css/style.css` — стили и адаптив mobile-first.
- `js/main.js` — меню, hero-слайдер, формы, WhatsApp, чат, lightbox, цели Метрики.
- `assets/images/` — локальные WebP-изображения и responsive-варианты.
- `robots.txt`, `sitemap.xml` — базовые SEO-файлы.
- `.nojekyll` — отключает обработку Jekyll на GitHub Pages.

## GitHub Pages

1. Создайте новый репозиторий на GitHub.
2. Загрузите всё содержимое этой папки в корень репозитория.
3. Откройте **Settings → Pages**.
4. В **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`.
6. Нажмите **Save**.

После публикации GitHub выдаст адрес вида `https://username.github.io/repository/`.

Для подключения `lscate.ru` лучше сначала убедиться, что GitHub Pages версия полностью утверждена, и только затем менять DNS домена.

## Проверка адаптива

Статически и через Chromium layout-тест проверены ширины: 390, 414, 430, 768, 1024, 1280, 1440 px. На этих ширинах `scrollWidth` совпадает с шириной viewport, то есть горизонтальный overflow не обнаружен. Проверены открытие burger menu, модальной формы, чата, вкладок портфолио и раскрытие отзывов.

Реальный iPhone Safari/WebKit в текущей среде недоступен, поэтому перед переключением основного домена рекомендуется дополнительно открыть опубликованный URL на iPhone Safari и Android Chrome.
