Love Story Catering — Core Web Vitals / performance static audit

Implemented in V6.0:
- Responsive hero image preloads remain in place for likely LCP resource.
- Below-the-fold images use loading=lazy, decoding=async and fetchpriority=low.
- Progressive blur-to-sharp reveal does not change image dimensions, so it does not introduce CLS.
- Existing width/height attributes retained for photographic images to reserve layout space.
- Yandex map iframe remains lazy-loaded.
- Yandex Metrika remains consent-gated and therefore does not block first render before consent.
- Second hero slide stays deferred until idle/after first screen.
- content-visibility:auto is enabled where supported for sections below the hero.
- Motion continues to honor prefers-reduced-motion.

Important: this is a static implementation audit, not CrUX field data. Real LCP/INP/CLS numbers should be checked after V6.0 is published at lscate.ru using PageSpeed Insights / Chrome UX Report under production network conditions.
